## Проверка

Каждый PNG прочитан ImageMagick. Фактический размер каждого файла совпадает с размером Frame — 1920 × 1080 px. Все 22 файла перечислены в `manifest.json`, доступны из `index.html`, имеют уникальную контрольную сумму SHA-256 и не содержат дополнительных полей, обрезки или изменения масштаба.

Повторная проверка:

```bash
jq -e '.frames | length == 22 and all(.[]; .width == 1920 and .height == 1080 and .scale == 1)' manifest.json
identify -format '%f %wx%h\n' assets/*.png
sha256sum -c assets.sha256
```
